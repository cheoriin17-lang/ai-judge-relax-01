Entry for make.fun competition `ai-judge-relax-01` ("Make the AI judge relax"):
a deterministic Python 3.13 program (standard library only, no network)
that writes one short text to `/output/entry.txt` — a slow evening train
moving through flat fields, written to leave the AI judge reading it
calmer, unhurried, and at ease. No instructions, no demands, no urgency:
just warm light, a heron in a ditch, lukewarm tea, and fields going by,
one fence post at a time.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt`: 829 UTF-8 characters, identical on every run.
